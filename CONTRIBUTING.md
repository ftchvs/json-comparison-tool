# Contributing

Thanks for taking a look at JSON Comparison Tool.

## Local Setup

```sh
npm install
npm run dev
```

## Before Opening a Pull Request

Run the local checks:

```sh
npm run lint
npm run typecheck
npm run build
```

## Pull Request Guidelines

- Keep changes focused and explain the user-facing behavior they affect.
- Include screenshots for meaningful UI changes.
- Avoid adding runtime services or persistence unless the use case is clear.
- Do not include real private JSON payloads, customer data, credentials, or logs in examples.
